Rendered instead of the menu by `/menu`, `/home`, `/order`, `/kiosk` and `/cus` when `branch.public()` returns None: two or more branches exist and the request said nothing about which. It is a question, not an error — the alternative was serving one branch's prices to the other's customer without saying so. A one-restaurant site never sees this: `branch.choices()` is empty below two, and `public()` answers with the only one long before the page gets here. Each tile is a plain link that adds `?r=` to the URL the customer is already on, keeping every other parameter (`?promo=`, `?ref=`, `?phone=`) — those come off QR stickers and WhatsApp threads, and dropping them turns a personalised link into a generic one. The choice is remembered in a cookie by the page it lands on, so this is asked once. -#}
